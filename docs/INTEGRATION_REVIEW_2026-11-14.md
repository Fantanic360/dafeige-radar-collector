# 2026-11-14 接入复核

本次复核修正了采集器的安全与采编契约，不代表所有平台已打通，也不代表生产调度已切换。

## 已修正

- 采编凭据仅发送到对应采编 origin；公开镜像无凭据。敏感请求不跟随跨来源跳转，不注入浏览器脚本。
- 写入 `/api/collection` 时按服务器字段白名单投影，审计 `extra` 留在本地。新作品 ID 不含点等不支持字符，已有原链复用原 ID。
- 实时来源名单、队列和待补正文来自采编 API；读取失败停止本轮，避免复活已移除来源。
- 原计划时刻决定出刊轮次，补采上限为 8；保留失败时间缺口、正文退避和原始发现时间。
- 元数据、节目简介、正文与字幕分别处理，文本长度不再用于证明全文已读。
- 未能证明完整覆盖的列表不能记 success；熔断未执行的目标不伪造新 checkedAt。
- 原子租约和请求幂等提供离线测试；未绑定真实鉴权和 D1 的示例路由默认关闭。

## 回传包验收结果

两轮共 52 条原链，`profiles` 与 `profileGaps` 均为空，因此没有新增个人主页证据。旧 observations 不导入生产成功游标。

维护者独立复核了 6 条 GitHub 发布说明、13 条 B站原作元数据及 17 条 Higgsfield 官方页面。GitHub 中 2 条已有，Higgsfield 中 1 条已正式收录；共新增 33 条作者发布记录。B站视频未获得原片或字幕的仍为 metadata。另有访问失败、日期冲突或未独立复核记录留待后续处理。

## 尚未接通

1. 抖音、小红书、微博、公众号等平台的获准会话或内容接口；当前浏览器驱动每轮使用临时 profile，不能宣称“拿到登录态即可复用”。
2. B站视频字幕、转写或原片核验流程。
3. 生产 Site 的 D1 与鉴权接线、远端租约领取/续租/释放，以及跨机并发验收。`integration/site` 是模板，不能直接当已部署功能。
4. 由获准执行环境实际运行修正版、回读公开镜像，连续三天验收。当前修复验证为离线测试，不是生产稳定性报告。

## 运行约定

- 使用 Node 24 或更新版本。
- Site 服务凭据仅从当前任务内存或临时进程输入取得，不写 `.env`、配置、日志、证据文件或仓库。
- 调度器显式传入 `--scheduled-for`，值为带时区的原计划时刻。不能用延迟启动后的当前时间替代。
- 常规内容更新继续通过 API 写入，不需要重新部署阅读台。
